# Kelvin Portfolio

A modern and responsive personal portfolio website built with React, Vite, and Tailwind CSS. This portfolio showcases my frontend development skills, projects, technical stack, and contact information through a clean and interactive user interface.

## Live Demo

[View Portfolio](https://personal-portfolio-taupe-chi-57.vercel.app/)

## Features

- Responsive design for desktop, tablet, and mobile
- Modern UI built with Tailwind CSS
- Reusable React components
- Interactive projects section with image preview modal
- Skills filtering system
- Contact form with validation
- Accessible and semantic structure
- Smooth hover and transition effects
- Sticky responsive navbar with mobile menu

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript (ES6+)
- Lucide React Icons
- React Icons
